# ミスタードリラー風 パズルアクションゲーム (Mr. Driller Clone)

HTML5 Canvas と Vanilla JavaScript で構築された2Dパズルアクションゲームです。

## 本日実装した機能とアップデート内容

### 1. ゲームスタート画面の実装
- ゲーム起動時にタイトル画面（スタート画面）を表示するように実装しました。
- スタート画面には以下を含めています：
  - タイトルロゴ（`MR. DRILLER`）
  - 目標メッセージ（`地下 500m を目指せ！`）
  - 操作方法ガイド（矢印キー/D-PADでの移動、スペースキー/DIGボタンでの掘り）
  - ルール説明（同色一括消去、AIR補給、落石注意、500m到達でクリア）
  - 点滅演出付きのスタート案内（`PRESS SPACE OR DIG TO START`）

### 2. フィールドの縦長化とカメラの縦スクロール機能
- ステージの深さを 500m (501行) に大幅拡張しました。
- プレイヤーのY座標（深さ）に合わせて画面表示領域が下にスムーズに追従・スクロールするカメラ機能（`updateCamera`）を実装しました。
- 描画処理およびブロック重力・落下待ち計算を表示領域付近（視界内）のブロックに限定することで、500mの大規模フィールドでも高いパフォーマンスを維持できるように最適化しました。

### 3. ゲームクリア判定 (地下マイナス500m)
- 地下 500m (`GOAL_DEPTH = 500`) にゴールを設定し、最下層に金色の「GOAL」ブロックを表示するようにしました。
- プレイヤーが 500m に到達した瞬間、ゲームクリア状態（`STATE_GAMECLEAR`）へ遷移します。
- クリア時には「STAGE CLEAR!」画面が表示され、到達メッセージと残りAIR（酸素）割合を表示します。
- UIの「DEPTH」表示にも現在の深さと目標深さ（例: `500m / 500m`）を表示します。

### 4. ゲームオーバー/ゲームクリアからのスタート画面復帰フロー
- 酸素切れまたはブロック下敷きによる「GAME OVER」、および500m到達による「STAGE CLEAR!」後、キー入力・タップ・画面クリックでいつでも最初のスタート画面に戻れるように遷移フローを構築しました。
- 状態遷移直後の連打や誤操作を防ぐため、クールダウン時間（`stateChangeCooldown`）を導入しています。

## 起動方法・開発手順

### ローカルサーバー起動
```bash
python3 -m http.server -b 0.0.0.0 3000
```
ブラウザで `http://localhost:3000` にアクセスしてプレイできます。
